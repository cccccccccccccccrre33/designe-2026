# База знаний студии

Источник: исследование владельца «DRIVE&KAVA — исследовательская база будущей
AI-дизайн-студии» (15.10.2026). Здесь — структурированные аналитические
выжимки нашими словами, а не копии материалов.

## Формат

Каждый файл — набор фрагментов `## Заголовок` с метаданными:

```
<!-- meta: id=SRC-DK-001; tier=A; tags=transitions,motion; kind=project; rights=public-reference-only; url=needs-url -->
```

| Поле | Значения |
|---|---|
| tier | A — первоисточник с подтверждённым авторством; B — профессиональные исследования; C — визуальный референс; D — непроверенное; M — метод студии (наша формулировка) |
| rights | `public-reference-only` — только ссылка и анализ, без копирования и обучения; `owned` — наши материалы |
| status | `research` (по умолчанию), `standard` (утверждено), `hypothesis`, `rejected` |
| url | ссылка; `needs-url` — источник без найденного адреса (сейчас один: интервью о прогнозе времени заказа) |

## Состав

- `sources/` — карточки источников по компаниям; `sources/inbox-2026-10-15.md` — все 125 ссылок из архива владельца, тир D до ручной проверки.
- `methods/` — переносимые методы студии (тир M).
- `practitioners/` — досье школ, **генерируются** из `studio/org/practitioners.json` (`npm run studio -- practitioners-docs`), вручную не редактируются.
- `archive/` — исходный архив ссылок владельца как есть (в поиск не индексируется).

## Правила

- Агент никогда не «является» человеком из источника — источник описывает метод.
- Тиры C и D не являются доказательством практики команды Drinkit/Dodo/amo.
- Изображения из портфолио не копируются в репозиторий и не используются для обучения.
- Новый архив ссылок: `npm run knowledge:ingest -- <файл.md>` создаёт
  `sources/inbox-<дата>.md` с тиром D для ручной проверки.
