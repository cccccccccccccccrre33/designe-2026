# DRIVE&KAVA — контекст продукта

Статус: standard (утверждено владельцем в брифе 15.10.2026). Краткая версия идёт
в контекст каждого агента — держите файл коротким.

## Что это
Собственная кофейня DRIVE&KAVA с залом и **драйв-окном для автомобилей**.
Мобильное приложение для предзаказа напитков.

## Окно — одно (уточнение владельца 15.10.2026)
Как McDrive, только **всё в одном окне**: заказ, оплата и выдача. Второго окна и
отдельной кассы для авто нет — окно не нумеруется. Окно в правом конце фасада
павильона (графитовые панели, деревянная вставка, табличка «drive&kava»), со
стороны водителя. Картой платят у окна: терминал подают из окна, гость прикладывает
карту или телефон, не выходя из машины. Фото, маршрут и правила подсказки —
`product/space/drive-window.md`.

## Жёсткие ограничения
- В приложении **оплаты нет**: платят только на месте. В оформлении гость лишь
  выбирает способ — **«Готівкою»** или **«Карткою»**; кнопка — «Замовити», не
  «Оплатити»; без полей карты, Apple/Google Pay и предоплаты.
- Гость выбирает напитки, настраивает, оформляет предзаказ и способ получения:
  **в зале** или **у вікні** (необязательный номер авто, интервал приезда).
- Тем, кто забирает у окна, нужна подсказка по реальному месту: маршрут,
  ориентиры, имя или номер заказа крупно, сумма и выбранный способ оплаты.
- Весь интерфейс приложения — **только на украинском**.
- Сейчас этап дизайна: экраны, ассеты, движение, спецификации. Код приложения
  не переписывается без отдельного разрешения.

## Меню (снимок v82, 28 позиций, `product/catalog.v82.json`)
Лимонади (5), Холодні напої (5), Гарячі напої (14), Drive Mood (4).
Лимонады и холодные — со льдом; горячие — с выбором молока и доплатой.
Часть цен уточняется.

## Текущее приложение
HTML/JS PWA + Android-обёртка (`D:\DriveKava\Drive_Kava_v81_drinkit`), прототип
редизайна v82. Были функции: LAB (генерация рецептов), печенье с предсказанием,
чаевые бариста, живой голос, уведомления от напитка, Liquid Glass нижняя панель.
Фото в v82 — AI-визуализация, перед коммерческим запуском заменить реальной
предметной съёмкой.

## Экраны (приоритет — ежедневные)
Ежедневные: главная, каталог, карточка напитка, настройка, корзина, активный
заказ / ожидание, получение. Реже: первый запуск, профиль, избранное, история,
LAB, персональные функции.

## Открытые продуктовые задачи (исследование, не реализация)
- Быстрое оформление без перегруза.
- Честное время готовности с учётом загрузки бариста (интервал, а не обещание).
- Снижение фиктивных предзаказов без оплаты — без вреда добросовестным гостям.
- Понятное получение в окне для авто: подсказка «Заберу у вікні» по реальному месту.
- Связь приложения с тем, что происходит в кофейне.
