# ADR-0006: Агент и модель — разные сущности

Статус: принято · 15.10.2026

## Решение
Профиль роли не содержит имени модели. Вызов объявляет класс задачи
(`classify`, `position`, `spec`, `critique`, `arbiter`…); модель выбирает
маршрутизатор по реестру, eval-оценкам, бюджету и правилу независимости.
Память, знания и история роли сохраняются при смене модели.

## Почему
bld-team держал 225+ ручных назначений «роль → модель» и историю их замен в
комментариях. Здесь назначения — по классам задач (≈10), меняются по
измерениям, а не вручную по ролям.
