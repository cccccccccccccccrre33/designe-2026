# ADR-0001: TypeScript на Node.js 24, минимум зависимостей

Статус: принято · 15.10.2026

## Контекст
bld-team написан на Python. Для студии ключевой инструмент — headless Chromium
(рендер экранов и движения), его родная экосистема — Node.js (Playwright).
AgentCore Runtime поддерживает Node.js direct code deployment (04.2026),
Lambda — Node.js 24, Evaluations — TypeScript-фреймворки (09.2026). На машине
владельца из сред выполнения есть только Node.js 24.

## Решение
- TypeScript, исполняемый напрямую Node.js 24 (встроенное удаление типов, без
  шага сборки). Поэтому в коде нет `enum`, `namespace` и параметров-свойств.
- Без runtime-зависимостей в ядре: HTTP через `fetch`, тесты через `node:test`.
- Единственная опциональная зависимость — `playwright-core` для рендера через
  установленный Chrome/Edge (без загрузки браузеров).
- AWS SDK подключается на этапе 5 только в облачных адаптерах.

## Последствия
Код bld-team не переиспользуется построчно — переносятся идеи (см. аудит).
Для Lambda потребуется бандлинг (esbuild) на этапе 5.
