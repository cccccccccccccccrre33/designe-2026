# ADR-0002: Экраны — это спецификация и код, а не сгенерированные картинки

Статус: принято · 15.10.2026

## Контекст
Владельцу нужны high-fidelity экраны, близкие к передаче разработке.
Генераторы изображений не дают стабильной украинской типографики, точной сетки,
повторяемых компонентов и состояний; результат нельзя измерить и точечно
исправить по замечанию «кнопки прозрачнее».

## Решение
- Агенты пишут **Screen Spec** — JSON-дерево слоёв на токенах дизайн-системы
  (`src/render/spec.ts`). Новые компоненты появляются через Design System
  Designer и версионируются.
- Рендерер превращает Spec в HTML/CSS и снимает PNG в разрешении устройства
  (iPhone 15 Pro: 393×852 pt, @3x) через headless Chromium.
- Фото напитков и сцены создаёт генератор изображений и вставляет слоями в
  объявленные зоны.
- Автопроверки читают геометрию и стили из DOM, а не «смотрят» на картинку.

## Последствия
+ Правка по замечанию — изменение Spec и повторный рендер, а не новая
  генерация. + Измеримость. + Прямой путь к handoff: токены, состояния, размеры.
− Свобода формы ограничена примитивами рендерера; экзотические эффекты
  добавляются как новые примитивы (например, `glass`).
