# ADR-0005: Специализация без fine-tuning на старте

Статус: принято · 15.10.2026

## Решение
Специализация агентов = профиль роли + карточки методов (RAG) + реестр
предпочтений + схемы вывода + eval. Fine-tuning откладывается до двух условий:
≥300 решений владельца с причинами и eval-подтверждённый потолок качества.
Обучение — только на материалах, на которые есть права.

## Почему
Знания о кейсах меняются и требуют ссылок; вкус владельца должен быть
отменяемым; публичные портфолио не дают права на обучение; fine-tuning не
поддерживается для большинства моделей нужного уровня и стоит дороже, чем
даёт на этом этапе.
