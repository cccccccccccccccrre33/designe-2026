# ADR-0004: Операционное состояние — в хранилище, решения — в Git через PR

Статус: принято · 15.10.2026

## Контекст
bld-team хранил доску задач, вики и дневники в JSON внутри репозитория и
пушил в main из каждого запуска: гонки, конфликты, шум, файл доски 171 КБ.

## Решение
- Состояние (инициативы, журнал шагов, ledger, outbox, сессии Telegram) —
  в хранилище: локально `.studio-data/` (не коммитится), в облаке DynamoDB.
- Git — система записи **решений и артефактов**: Screen Spec, превью, отчёты
  ревью, `studio/decisions/DEC-*.md`. Только через ветки `studio/*` и PR.
- Медиа больше 1 МБ — S3 со ссылкой и хэшем в Git.

## Последствия
История Git читается как история решений. Бот не пишет в main напрямую.
